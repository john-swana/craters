Class RigidBody

RigidBody class for 2D physics simulation. Supports dynamic and static bodies, forces, impulses, and collision response.

Units: positions in px, time in seconds, velocities in px/s, accelerations in px/s², angles in radians. Collision response is single-pass and impulse-based; collisions and forces never rotate a body (there is no inertia/torque model). Pair a body with a SAT shape and copy position to shape.pos after integrate and resolveCollision.

Sleeping: a body that stays slow for sleepTimerMax steps falls asleep and is skipped until woken. Apply per-step forces such as gravity with applyForce(force, false) so resting bodies can fall asleep.

applyForce

  • applyForce(force: Vector, wake?: boolean): void

  • Apply a force (mass × px/s²) to the center of mass. It accumulates until the next integrate, which clears it, so apply continuous forces (e.g. gravity) every step. Ignored by static bodies.

    Parameters

    • force: Vector

      the force to add

    • wake: boolean = true

      wake the body and restart its sleep timer, like wake (default true). Pass false for forces applied every step, such as gravity, so a resting body can fall asleep; a sleeping body then ignores the force and stays asleep.

    Returns void

integrate

  • integrate(dt: number): void

  • Integrate physics using semi-implicit Euler method.

    Parameters

    • dt: number

      elapsed time in SECONDS. Velocities are therefore in px/s and accelerations in px/s² — which is what the internal tuning constants (maxSpeed = 4000 px/s, the resting-contact threshold) assume. With a fixed-step RenderLoop, pass loop.deltaSeconds (NOT loop.delta, which is milliseconds — that would scale every velocity by 1000×).

      Static bodies are skipped. The sleep state is updated first, from the velocity the previous step left behind (after its collision response), and a sleeping body only has its forces cleared. Otherwise: velocity += force/mass·dt, damping, position += velocity·dt, angle += angularVelocity·dt, forces cleared.

    Returns void

    • Defined in rigidbody.ts:203

resolveCollision

  • resolveCollision(other: RigidBody, response: Response): void

  • Resolve a collision using impulse-based response.

    Argument order matters: response must come from a SAT test whose FIRST shape belongs to this body, i.e. testPolygonPolygon(thisShape, otherShape, response) (response.overlapN points from this body toward other). Swapping the order pushes the bodies into each other.

    Resting contact: an approach slower than 2 px/s plus the normal velocity the two bodies gained from forces in their last step (e.g. one step of gravity) counts as resting rather than as an impact.

    Steps: returns if both bodies are static; wakes a sleeping body only if the contact is an impact (resting and separating contacts leave it asleep, and awake bodies keep their sleep timers); a body that is still asleep acts as immovable for this contact; moves the bodies apart along the normal by 40% of (overlap − 0.5 px), split by inverse mass; returns if already separating; scales the approach speed down for overlaps > 8 px (to zero at 16 px); applies a normal impulse with min(restitution) (0 for resting contacts); caps each dynamic body's speed at 4000 px/s; applies Coulomb friction with the average friction. No rotation is produced.

    Positions change, so re-sync shapes (shape.pos.copy(body.position)) afterwards.

    Parameters

    • other: RigidBody
    • response: Response

    Returns void
